Applied Learning Activities

Rehearse the concept before the evidence package

Twelve varied, source-grounded activities support lessons, revision, fast finishers and relief teaching. They are formative practice, not assessment.

Module 1

Graphic Design & Communication

M01 · M01S01 · 18 minutes

Context before colour: safety-sign evidence audit

A safety-sign graphic should be read as a complete communication, not guessed from colour alone. Sort the statements, then write a short evidence-based critique.

Source concept: Interpret a safety sign through its complete visual system and viewing context rather than one familiar feature.

  1. Read each statement without imagining a local workshop rule.
  2. Sort it as observed visual evidence, a context question, or an unsupported conclusion.
  3. Check the sort, revise any weak decisions, then complete the three-sentence critique.
Part 1: Classify each statement about a fictional sign shown in a busy public corridor.
Part 2: Write a three-sentence critique: identify one visual feature, explain its likely effect on recognition, then name one context fact you would check before recommending a redesign.
  • Names visible evidence
  • Explains an effect rather than a preference
  • Does not claim a local safety rule
  • Includes audience, purpose or location

Not started

Return to the lesson
Printable or low-tech path

Place the six statements under three headings, then complete the critique scaffold. Keep the final three headings visible when printing.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M01 · M01S02 · 20 minutes

Vector workflow repair

A neat vector file can still communicate poorly. Rebuild the workflow, then diagnose two faults that software precision alone cannot fix.

Source concept: Use a deliberate vector workflow in which editable construction and communication checks lead to an appropriate export.

  1. Put the workflow stages in a defensible order.
  2. Check the sequence and read the feedback.
  3. For each fault, select the most useful next check and explain why.
Part 1: Order the stages from the first design decision to the final output check.
Part 2: Choose the most useful response to each fault.

The paths are smooth and aligned, but the symbol disappears against the background.

The editable file looks correct, but the exported text is difficult to read at its destination.

Not started

Return to the lesson
Printable or low-tech path

Number the seven workflow cards, then circle one response for each fault and write one sentence explaining the selected check.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M01 · M01S03 · 22 minutes

Design rationale and source-rights decision lab

Responsible design involves both visual reasoning and source responsibility. Decide whether each fictional proposal can proceed, needs revision, or must pause for guidance.

Source concept: Connect design principles to audience and purpose while pausing when provenance, permission or cultural authority is uncertain.

  1. Triage each proposal using only the evidence supplied.
  2. Check the feedback before revising.
  3. Rewrite one weak personal-preference statement as a design rationale linked to audience and purpose.
Part 1: Select Proceed, Revise, or Pause and seek guidance.
Part 2: Rewrite “I centred everything because it looks neat” as a rationale that names an audience need, a design principle and the intended effect.
  • Links to audience
  • Names a principle such as composition, proportion, balance, tone or contrast
  • Explains effect
  • Avoids unsupported rights or cultural claims

Not started

Return to the lesson
Printable or low-tech path

Mark P, R or G beside each proposal, write the evidence for the choice, then complete the rationale scaffold.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

Module 2

Architectural Drawing

M02 · M02S01 · 24 minutes

Spatial relationship studio

A compact floor plan begins with relationships, not detailed walls. Sort the planning statements, then build a written bubble-plan proposal that can still be revised.

Source concept: Test zones, adjacency and circulation before detailed drafting, then use precedent as evidence rather than a template.

  1. Classify each statement by the planning idea it tests.
  2. Use the supplied class spaces without inventing dimensions.
  3. Write one relationship proposal and one question that still needs evidence.
Part 1: Identify the planning idea used in each statement.
Part 2: Using the class exercise spaces, describe one possible set of zones, one adjacency to test and one circulation conflict to avoid. Finish with one source or context question.
  • Uses relationship language
  • Does not invent exact room dimensions
  • Treats the arrangement as a proposal
  • Names evidence still needed

Not started

Return to the lesson
Printable or low-tech path

Place the class spaces as labelled circles, draw and label relationship arrows, trace one movement path, then answer the four scaffold prompts.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M02 · M02S02 · 20 minutes

Cross-view detective

CAD can draw the wrong information very precisely. Follow one fictional window through a plan, elevation and section, then identify what must be checked.

Source concept: Trace one architectural feature through coordinated views and diagnose contradictions before output.

  1. Read each case file carefully; no dimensions are needed.
  2. Choose whether the views are consistent, inconsistent or lack enough evidence.
  3. For one inconsistent case, write the smallest useful repair process.
Part 1: Diagnose each drawing set.

The plan places one window near the left end of a wall. The matching elevation places the same window near the right end.

The plan and elevation agree on the opening. A section passes through the opening and shows uninterrupted solid wall.

The views agree on location, but the source does not state the window width.

The plan, elevation and relevant section all show one corresponding opening, and no unsupported dimensions have been added.

Part 2: Choose one inconsistent case and describe a repair routine that starts from the controlled source, updates geometry, then rechecks related annotation and output.
  • Starts with source evidence
  • Names every affected view
  • Does not invent a dimension
  • Includes final readability

Not started

Return to the lesson
Printable or low-tech path

Mark C, I or ? for each case. On the back, write the four-step repair routine and underline the controlled source check.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M02 · M02S03 · 22 minutes

Coordination ripple map

One change can affect several drawings and several kinds of reasoning. Map the ripple created when a fictional window moves.

Source concept: Follow one design change through sustainability reasoning, relevant views and professional questions without making unsupported compliance claims.

  1. Select every representation or decision that needs review.
  2. Classify each claim by what the drawing evidence can actually support.
  3. Write a concise revision note that another reader could follow.
Part 1: A window moves after a review of room use, orientation, daylight and shade. Which items need review?
Part 2: Classify the claims after the drawing update.
Part 3: Write a revision note naming the change, reason, affected evidence and one claim you will not make.

Return to the lesson
Printable or low-tech path

Place the changed element in the centre, draw arrows to affected drawings and reasons, then complete the claim-boundary box.

Module 3

Engineering Drawing

M03 · M03S01 · 22 minutes

Projection choice workshop

Different views answer different questions. Match each communication need to a useful representation, then rebuild the freehand routine.

Source concept: Choose the smallest useful combination of views for a communication need and construct freehand views through alignment.

  1. Choose the view that best answers each question; one view may not answer everything.
  2. Order the freehand routine.
  3. Recommend a compact view set for a fictional bracket and justify every included view.
Part 1: Match the need to the most directly useful representation.
Part 2: Order the freehand view-building routine.
Part 3: For a fictional bracket with a hidden internal hole, name the smallest useful view set and explain what question each view answers.
  • Each view adds different information
  • Includes a way to reveal the hidden feature
  • Uses alignment logic
  • Does not add dimensions

Not started

Return to the lesson
Printable or low-tech path

Draw lines between four needs and view types, number the freehand routine, then make thumbnail boxes for the proposed view set.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M03 · M03S02 · 24 minutes

Design-intent dependency test

Two CAD models can look identical before a change but behave very differently afterwards. Decide which model preserves the intended relationship and audit the claims that follow.

Source concept: Model relationships so authorised changes preserve design intent, while keeping material and manufacturing claims within the source evidence.

  1. Compare the two fictional model structures.
  2. Classify each claim as supported or unsupported by the model evidence.
  3. Write a dependency statement for one feature from the teacher source drawing.
Part 1: A hole must remain centred across a rectangular base. Which model structure better represents that intent?

Model A constrains the hole centre to the base centre relationship. Model B fixes the hole at an unrelated position. The authorised base width changes.

Part 2: What can a smooth, correctly related CAD model demonstrate?
Part 3: Choose one feature from an authorised source drawing and record its source, intended relationship and the check you would perform after an authorised change.
  • Uses only supplied information
  • Names a relationship
  • Includes a cross-view or model check
  • Avoids material, cost, load and process claims

Not started

Return to the lesson
Printable or low-tech path

Draw a base and centred feature without dimensions, add relationship arrows, then mark each claim S or U with a reason.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M03 · M03S03 · 24 minutes

Drawing and motion release audit

Technical-looking output is not the same as verified information. Separate size, location and controlled-standard information, then test what an animation can honestly show.

Source concept: Communicate size and location without duplication, and limit assembly or animation claims to what the digital evidence demonstrates.

  1. Classify the drawing information.
  2. Check each release claim against the evidence described.
  3. Write one final release note that names both demonstrated evidence and a limitation.
Part 1: Classify each item for a fictional plate with a hole.
Part 2: Decide whether each claim passes the described evidence gate.

The modelled mate permits the shown digital movement.

Smooth animation proves the physical mechanism is safe and manufacturable.

The drawing uses only dimensions supplied by the controlled source.

CAD-generated annotations are automatically standard-compliant.

Part 3: Complete: “The drawing and assembly demonstrate …; they do not yet demonstrate …; before any stronger claim I would need …”.
  • Names visible drawing or motion evidence
  • States a physical or standards limitation
  • Identifies an authorised evidence source
  • Does not invent a value or symbol

Not started

Return to the lesson
Printable or low-tech path

Place four drawing cards under S, L, C or D, mark each claim Pass or Hold, then complete the three-part release note.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

Module 4

Student Negotiated Project

M04 · M04S01 · 25 minutes

Brief refinery

“I want to make a poster” names a format, not a complete graphics problem. Sort the brief components, then refine a vague idea without choosing software or adding unsupported requirements.

Source concept: Turn a topic into a focused graphics brief with observable criteria, realistic constraints and an approval-ready ethical source plan.

  1. Match each statement to the brief component it supplies.
  2. Identify the weak criterion.
  3. Write a compact brief outline and run the approval-readiness check.
Part 1: Match each statement to the brief component.
Part 2: Replace “It must look professional” with one observable criterion linked to the chosen audience and purpose.
  • Observable
  • Audience-linked
  • Does not prescribe an unapproved solution
  • Can be evaluated with evidence
Part 3: Create an outline containing problem, audience, purpose, context, essential evidence, required/preferred/optional features, criteria, constraints, source or privacy checks and the question to take to your teacher before production.

Not started

Return to the lesson
Printable or low-tech path

Use the twelve labelled boxes from the digital outline. Star required evidence, circle unresolved ethical or source questions and take the completed canvas to the current approval discussion.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M04 · M04S02 · 25 minutes

Scope rescue board

A project drifts when optional work consumes time needed for the approved purpose. Rescue a fictional project by triaging features, ordering dependencies and preserving useful versions.

Source concept: Use divergent ideas, meaningful milestones, dependencies and recoverable versions to keep digital development connected to the approved brief.

  1. Classify work as protect, simplify/defer, or investigate.
  2. Order the project stages by dependency.
  3. Record one scope-control decision and one stable recovery point.
Part 1: The project is halfway through and behind schedule. Triage each item.
Part 2: Order a controlled development pathway.
Part 3: Record one project-control decision.
  • Decision links to brief
  • Optional work is not treated as required
  • Recovery point is identifiable
  • No invented file-naming or submission rule

Not started

Return to the lesson
Printable or low-tech path

Cut or copy items into Protect, Defer and Investigate columns, number the development pathway, then complete the six-field decision log.

Formative practice only — not formal assessment, folio submission, teacher-observed evidence or a competency decision.

M04 · M04S03 · 25 minutes

Evidence-to-evaluation studio

A polished image and a pile of screenshots do not prove the brief was met. Select evidence for a purpose, improve the feedback questions, then construct an evaluation.

Source concept: Select meaningful presentation evidence, ask criterion-linked feedback questions and build evaluation through claim, evidence and reasoning.

  1. Choose the more useful feedback question in each pair.
  2. Order claim, evidence and reasoning.
  3. Write an evaluation paragraph that includes a strength, limitation and next improvement.
Part 1: Choose the question that produces more useful evidence.

Choose the stronger question.

Choose the stronger question.

Choose the stronger question.

Part 2: Order the parts of an evaluation unit.
Part 3: Evaluate one fictional or personal graphic against one approved criterion. Include one strength, one limitation and one specific next improvement.
  • Returns to criterion
  • Uses selected evidence rather than a process list
  • Explains effect on audience or purpose
  • Does not claim privacy, rights or cultural permission without checking
